# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-10-21

### Added
- Zero-GPU pure-terminal 3D Signed Distance Field (SDF) raymarcher in safe Rust.
- 4-Tap tetrahedral gradient calculation for surface normals.
- Physically Based Rendering (PBR) microfacet specular lighting and soft cone-traced shadows.
- Parallax holographic head-tracking over V4L2/OpenCV-free light field decomposition.
- High-performance Rayon SIMD execution delivering >220 FPS in pure ANSI terminals.
